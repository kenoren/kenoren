## 🧠 Lexpacte AI

Development of a **sovereign AI solution for analyzing SME transfer contracts**.

Lexpacte helps **lawyers and chartered accountants** detect **legal red flags** such as:

- GAP clauses  
- Non-compete clauses  
- Change of control clauses
